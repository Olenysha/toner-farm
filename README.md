# 🖨 Тонер-фарм

Система учёта расходных материалов (тонеров/картриджей) для IT-отдела.
Работает локально на ноутбуке в корпоративном Wi-Fi, управление — с телефона
через сканирование штрихкодов EAN-13 на коробках.

## Возможности

- **Сканирование EAN-13** камерой телефона в непрерывном режиме (html5-qrcode), со звуком и вибрацией
- **Установка тонера в 3 касания**: скан → тап по принтеру на карте → «Да»
- **Интерактивная карта этажа** с pinch-to-zoom: статусы принтеров цветными индикаторами (🟢🟡🔴⚫)
- **Два этажа (5 и 9)**: выезжающее меню выбора этажа на карте, у каждого этажа свой план и свои принтеры, БД общая
- **Автосписание** старого тонера при замене (пишется в историю как `auto_depleted`)
- **Обучение новых штрихкодов**: неизвестный EAN → форма с названием, цветом, совместимыми принтерами
- **История операций** с фильтрами и экспортом в Excel
- **Статистика**: замены по месяцам, средний срок службы, топ принтеров, остатки (Chart.js)
- **SNMP-мониторинг**: фоновый опрос принтеров по IP каждые 10 минут — реальный уровень тонера (прогресс-бары в попапе), счётчик страниц, алерты; статус на карте по уровню (≤5% красный, ≤20% жёлтый)
- **Админка**: принтеры (в т.ч. drag-and-drop по карте), barcode_map, смена плана этажа, резервные QR-стикеры (печать на A4)
- **Автобэкап** базы раз в день в `backups/` (хранятся последние 14)

## Стек

Python 3.8+ (проверено на 3.8–3.11), Flask, SQLite, vanilla JS + CSS (адаптив, тач-френдли).
Все JS-библиотеки локальные (`static/js/`), без CDN. openpyxl для Excel, qrcode+Pillow для QR.

## Быстрый старт (Windows)

Просто запустить **`start.bat`** — он сам создаст виртуальное окружение,
поставит зависимости и поднимет сервер. Если папку проекта перенесли на
другую машину (или обновили Python), `start.bat` заметит сломанный venv
и пересоздаст его под текущую версию Python.

Ручной вариант (любой Python 3.8+):

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

> ⚠️ Папку `.venv` нельзя переносить между машинами — она жёстко привязана
> к пути установки Python. После переноса проекта удалите `.venv`
> или просто запустите `start.bat` — он сделает это сам.

Открыть `http://localhost:5000`. База `database.db` создаётся автоматически
с демо-данными (3 принтера, 2 модели тонеров).

## Запуск в сети с телефона (HTTPS)

Камера в мобильном браузере работает только по HTTPS, поэтому:

1. **`open-port-5000.bat`** — один раз, откроет порт 5000 в брандмауэре
   (сам запросит права администратора)
2. **`setup-https.bat`** — один раз в каждой новой сети: определит текущий IP,
   выпустит сертификат mkcert и пропатчит `app.py`
3. Установить корневой сертификат mkcert на телефон (один раз):
   файл `static/rootCA.pem` отправить на телефон → установить как сертификат ЦС
   (подробная инструкция выводится в конце `setup-https.bat`)
4. `python app.py` → с телефона открыть `https://<IP-ноутбука>:5000`

При смене сети/IP достаточно повторить шаг 2 — `app.py` сам определяет
текущий IP и подхватывает нужный сертификат.

> ⚠️ Сертификаты, ключи (`*.pem`) и `mkcert.exe` в репозиторий не входят
> (см. `.gitignore`) — не коммитьте их.

## Структура

```
toner_farm/
├── app.py               # Flask: схема БД, сидинг, бэкап, все роуты и API
├── requirements.txt

├── setup-https.bat/ps1  # настройка HTTPS через mkcert

├── database.db          # SQLite (создаётся при первом запуске)
├── backups/             # ежедневные бэкапы БД
├── static/
│   ├── style.css
│   ├── floor_plan.png   # план-заглушка (планы этажей меняются из админки)
│   ├── js/              # html5-qrcode, Chart.js (локально, без CDN)
│   └── qr_codes/        # сгенерированные резервные QR
└── templates/           # base + index/scan/item/admin/history/stats/qr_print
```

## Схема БД

- `barcode_map` — EAN-13 → модель, цвет, совместимые принтеры, ресурс (page_yield)
- `toners` — учёт тонеров: `stock` / `installed` / `depleted`
- `printers` — справочник принтеров, координаты на карте, этаж (`floor_id`), 4 тонер-слота
- `operations` — журнал: `install` / `return` / `auto_depleted`
- `floor_plans` — этажи (5 и 9) и их планы; у каждого этажа одна активная картинка
- `snmp_readings` — история SNMP-опросов: уровни тонера (%), счётчик страниц, статус, алерты (JSON)
