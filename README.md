# 🖨 Тонер-фарм

Система учёта расходных материалов (тонеров/картриджей) для IT-отдела.
Работает локально в корпоративной сети, управление — с телефона
через сканирование штрихкодов EAN-13 на коробках.

## Возможности

- **Сканирование EAN-13** камерой телефона в непрерывном режиме (html5-qrcode), со звуком и вибрацией
- **Установка тонера в 3 касания**: скан → тап по принтеру на карте → «Да»
- **Несколько предприятий**: у каждого свои этажи, планы и принтеры; переключение на карте, склад и справочники общие
- **Интерактивная карта этажа** с pinch-to-zoom: статусы принтеров цветными индикаторами, размер иконок и подписей настраивается
- **Автосписание** старого тонера при замене
- **Склад по количеству**: приход/списание N штук по EAN, остатки по моделям и по принтерам (страница «Наличие»)
- **История операций** с фильтрами и экспортом в Excel
- **Статистика**: замены по месяцам, средний срок службы, топ принтеров, остатки (Chart.js)
- **SNMP-мониторинг**: фоновый опрос принтеров по IP — реальный уровень тонера, счётчик страниц, алерты, метка давности опроса
- **Админка**: предприятия, этажи, принтеры (drag-and-drop по карте), загрузка планов, резервные QR-стикеры
- **Доменная авторизация (AD/LDAP)**: роли по группам — `TonerFarm-View` и `IT_support`
- **Автобэкап** базы раз в день

## Быстрый старт (Docker)

```bash
# 1. Скопируйте пример переменных окружения (опционально)
cp .env.example .env

# 2. Запустите
docker compose up -d --build
```

Откройте `http://<host>:5000/login`.

Если домен AD недоступен, используйте локальный fallback-логин:
- логин: `admin`
- пароль: из переменной `TF_LOCAL_ADMIN_PASSWORD` (по умолчанию — пустой, т.е. выключен)

### HTTPS для телефона

Камера в мобильном браузере работает только по HTTPS. Рекомендуется поставить
любой reverse proxy (nginx, Caddy, Traefik) с сертификатом Let's Encrypt / корпоративным CA.

Если reverse proxy нет, можно поднять TLS прямо в контейнере:

1. Положите пару `cert.pem` + `key.pem` в `./certs/`.
2. Раскомментируйте в `docker-compose.yml`:
   - `CERT_FILE=/app/certs/cert.pem`
   - `KEY_FILE=/app/certs/key.pem`
   - `./certs:/app/certs:ro`
3. `docker compose up -d`

### Данные

Все данные живут в `./data/`:

- `./data/database.db` — основная БД
- `./data/alerts.db` — справочник SNMP-алертов
- `./data/backups/` — ежедневные бэкапы

При первом запуске папка `data/` создаётся автоматически.

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TF_DOMAIN` | `farm.local` | Домен для LDAP |
| `TF_LDAP_PORT` | `389` | Порт LDAP |
| `TF_VIEW_GROUP` | `TonerFarm-View` | Группа «только чтение» |
| `TF_EDIT_GROUP` | `IT_support` | Группа «редактирование + админка» |
| `TF_LOCAL_ADMIN` | `admin` | Локальный fallback-логин |
| `TF_LOCAL_ADMIN_PASSWORD` | *(пусто)* | Пароль fallback (пусто = выключен) |
| `SNMP_COMMUNITY` | `public` | SNMP community |
| `SNMP_INTERVAL` | `600` | Интервал SNMP-опроса, сек |
| `CERT_FILE` / `KEY_FILE` | — | Путь к сертификату и ключу внутри контейнера |

## Структура

```
toner_farm/
├── app.py                 # Flask-приложение, точка входа
├── auth.py                # Доменная авторизация + локальный fallback
├── db.py                  # SQLite: схема, миграции, сид, бэкапы
├── snmp_monitor.py        # Фоновый SNMP-опрос (pysnmp 7)
├── config/
│   ├── constants.py       # Константы (цвета-слоты, SNMP, карты)
│   ├── alerts.py          # Справочник SNMP-алертов
│   ├── seed.json          # Демо-данные принтеров/штрихкодов
│   └── printer_ip_map.json# Карта имя принтера → IP
├── templates/             # HTML-шаблоны
├── static/                # CSS/JS, планы этажей, QR-коды
├── Dockerfile
├── docker-compose.yml
├── entrypoint.sh          # Запуск через Gunicorn
└── requirements.txt
```

## Стек

Python 3.13, Flask 3.1, Gunicorn, SQLite, pysnmp 7, vanilla JS + CSS.
