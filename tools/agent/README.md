# Удалённый SNMP-агент

Используется, когда принтер находится в другой сети, а сервер Тонер-Фарм не может достучаться до него напрямую. Агент запускается на устройстве в той же сети, что и принтер (Android через Termux, Raspberry Pi, старый ноутбук и т.п.), опрашивает принтер по SNMP и отправляет данные на сервер через HTTPS.

## Настройка сервера

1. В `.env` (или в переменных окружения) задайте токен:
   ```bash
   AGENT_TOKEN=случайная-строка
   ```
2. Перезапустите сервер.
3. Убедитесь, что сервер доступен агенту по сети (по имени ноутбука или IP).

## Установка агента на Android (Termux)

1. Установите Termux из F-Droid (не из Google Play).
2. В Termux выполните:
   ```bash
   pkg update
   pkg install python
   pip install pysnmp==7.1.29 requests
   ```
3. Скопируйте файл `snmp_agent.py` на телефон (например, через `scp` или в папку Termux).

## Запуск агента

Задайте переменные и запустите:

```bash
export SERVER_URL="https://имя_ноутбука:5000/api/agents/snmp_report"
export AGENT_TOKEN="случайная-строка"
export PRINTER_IP="10.0.0.50"
export PRINTER_ID="123"   # id принтера в Тонер-Фарм (можно узнать в админке)
export INTERVAL="600"     # секунд между опросами
python snmp_agent.py
```

Чтобы агент работал фоном, используйте `nohup`:

```bash
nohup python snmp_agent.py > agent.log 2>&1 &
```

## Проверка

На сервере откройте `/logs` или посмотрите `logs/access.log` — должен приходить POST `/api/agents/snmp_report` с `printer_id` и уровнями тонера.

## Безопасность

- `AGENT_TOKEN` должен быть длинным и случайным.
- Передавайте токен только надёжным устройствам.
- Если сертификат самоподписанный, агент по умолчанию не проверяет SSL (`VERIFY_SSL=false`). Для продакшена используйте нормальный сертификат и включите `VERIFY_SSL=true`.
